# 📁 File Organizer

A Python tool that automatically organizes files in a folder based on their file extensions.

## 📝 About The Project

File Organizer is a Python automation project that helps users clean and organize messy folders.
The program detects file types and moves them into related folders automatically.

## ✨ Features

- Automatically categorize files
- Create folders based on file types
- Move files using Python
- Organize images, videos, music, documents, programs, and zip files
- Move unknown folders into a separate folder
- Generate file organization reports

## 📂 Supported File Types

| Category | Extensions |
|----------|------------|
| Images | .jpg, .png, .gif, .jpeg |
| Videos | .mp4, .mkv |
| Music | .mp3, .wav |
| Documents | .pdf, .docx, .txt |
| Programs | .exe, .msi |
| Zip Files | .zip, .rar |

## 🛠 Technologies

- Python
- OS module
- Shutil module
